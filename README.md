# Terry Flow

局域网多人使用的无限画布生图 / 生视频服务。**所有生成都经 [terry2api](../terry2api) 聚合API**（Flow、ChatGPT、小云雀、LibTV、Lovart 都在它后面），
画布自己只连这一个地址，另外可选接本机的 ComfyUI 做放大；不再直接处理 flow2api / gpt2api。

- 卡片式工作流：**生成卡片**（提示词 / 模型 / 比例 / 分辨率 / 张数）→ 结果图片出现在卡片右侧。
- **连图**：从图片右侧圆点拖线到生成卡片左侧，该图就作为参考图；选中图片后，下方的选择条里「新建生成卡片」会新建一张已连好线的卡片（选多张图就一起作为参考）；
  选中单张图时选择条还有「下载」和删除，选中多张图时有「合并为集合」。
- 拖入图片 / 上传按钮 / Ctrl+V 粘贴都能把图片放上画布；双击图片大图预览，可下载原图。
- **参考集合**（底部「＋ 参考集合」或按 R）：把多张参考图放进一个节点，按槽位顺序排列；点空槽位或把图片拖到槽位上即可添加（一次拖多张会自动追加槽位），
  拖动卡片调整顺序，「✕」先清空图片、再点一次移除空槽位，选中集合后 Ctrl+V 可粘贴图片进去。一个集合可以连给任意多个生成卡片，卡片会按顺序拿到里面所有图片；
  框选画布上的图片后，选择条（出现在选中图片的下方）上的「合并为集合」可一键放进去，「新建生成卡片」则新建一张已连好这些参考图的卡片。
- 提示词里用 `<Picture N>` 引用第 N 张参考图（按连线顺序编号）：输入 `@` 弹出参考图菜单（↑↓ 选择，Enter/Tab 插入，Esc 关闭），
  粘贴带 `<Picture N>` 的文字会自动显示成带缩略图的标签；点标签可替换。发给各来源时由聚合API按它们各自的写法改写（Flow 是 @N，小云雀是「图片N」，ChatGPT 是「第N张图」）。
- **编号不会错位**：每张卡片记住自己每张参考图的编号，换序、清空槽位都不会让 `<Picture N>` 指到别的图（已不存在的引用显示为红色标签）。
  提交时按编号排序发送参考图，并把提示词里的标签改写成「第几张发送的图」，所以提示词引用的图和实际提交的图一定一致；失效的引用会被丢掉并在卡片上提示。
- **一次拖入多张图**（拖拽、粘贴或上传多张）会弹出悬浮菜单：「散开」每张一个图片节点，或「集合」放进一个参考集合；按 Esc 或点空白处取消。
- **合并 / 解散**：框选图片后「合并为集合」会用集合替换这些散图，连线和提示词里的编号自动转给集合；集合标题栏的「解散」把它拆回独立图片节点，连线和编号保持不变。
- **图标**：生成卡片是香蕉、参考集合是四宫格、图片是图片图标，「生成」按钮带星光，左上角是品牌标志。
- **额度**：右上角用户名左侧显示 Nano Banana 2.1 今日额度（已用 / 总数，如 `3 / 1000`）和进度条，用到 70% 变黄、90% 变红；鼠标悬停看各模型用量。所有用户共用同一个 Flow 账号，每分钟和每次出图后刷新。
- **自动对齐**：左下角缩放按钮下方的对齐按钮（亮色为开启，设置会记住）。开启后拖动节点会吸附到其他节点的边缘和中心，并显示粉色虚线辅助线。
- 选中卡片或图片后，拖动边框和四角即可自由调整宽高（图片保持比例），尺寸随画板保存。
- 任务在服务端运行：关掉页面也不丢，重新打开会继续显示进度和结果。
- 多人并发：每张卡片的每一张图都是独立任务并行发给聚合API；各来源的并发上限和排队由聚合API负责，超出的任务会显示「排队中」。
  画布只额外限制「每个用户同时发给 Flow 的张数」。
- 每个用户的画板分开保存（输入名字即可，没有密码，仅适合可信局域网）。

## 运行

```
python -m venv venv
venv\Scripts\pip install -r requirements.txt
copy config.example.json config.json   # 填聚合API地址（gateway_url）
cd web && npm install && npm run build  # 生成 web/dist
TerryFlow.bat                           # 一键：拉取更新 → 检查/部署环境 → 启动控制台；默认 http://<本机IP>:8870
```

画板、图片、任务记录保存在 `data/`（`canvas.db` 和 `assets/`）。

## 在 config.json 里关闭选项

```json
{
  "disabled_sizes": ["4K"],
  "user_concurrency": 2
}
```

- 关闭某个 Flow 模型：在聚合API管理页「来源 → Flow → 设置」的「关闭的模型」里填（对所有调用方生效）。
- `disabled_sizes`：关闭分辨率（`"1K"` / `"2K"` / `"4K"` / `"6K"`）。也可以在控制台“设置”里把某个分辨率的来源设为“关闭”。
- `user_concurrency`：每个用户同时生成的任务数上限（所有模型、跨所有卡片，默认 4）；超出的任务在队列里等待。
- 改完重启服务生效；画板里已经选了被关闭选项的卡片，打开时会自动改成可用的值。

## ComfyUI 放大（可选）

在控制台点“设置”：“分辨率”页填 ComfyUI 地址，并为 1K / 2K / 4K / 6K 各选来源：Flow 原生、SeedVR2 放大、PiD 放大或关闭。选放大的分辨率，服务器会自动让 Flow 先出较小的一档，再放大到该分辨率（4K = 长边 4096，6K = 6144），不需要手动配尺寸。画板里选中一张图，选择栏会出现“放大到 4K”，结果放在右边的新图里。设置窗口有四页：「通用」（端口、超时、上传上限）、「聚合API」（地址、Key、任务超时）、「Flow 出图」（每个用户同时发给 Flow 的张数、关闭的 Flow 模型、各分辨率由谁来出）、「ComfyUI」（地址和放大用的模型文件）。保存后大部分设置立即生效，端口、聚合API地址 / Key、每用户 Flow 张数需要重启（保存时会询问）。

## 已知限制

- 没有账号体系；同一个名字就是同一个人。
- 同时生成的数量受各来源的账号额度和聚合API的并发上限限制，积分 / 额度是共享的。

## 视频生成（小云雀 / LibTV / Lovart）

底部「视频生成」（或按 V）新建视频生成卡片，视频由聚合API里的小云雀、LibTV、Lovart 生成。

- 模型下拉里列出 terry2api 里已配置平台的视频模型；比例、分辨率、时长、是否生成声音按所选模型显示。
- **连图**和生成卡片一样：从图片 / 参考集合连到视频卡片。「参考图用法」默认自动：1 张 = 首帧，2 张 = 首尾帧，3 张以上 = 参考图；也可以设成全部作参考图。
  参考图的 `<Picture N>` 引用（输入 `@`）同样可用。选中图片后选择条里的「做成视频」会新建一张已连好线的视频卡片。
- 结果是画布上的**视频节点**（可直接播放、下载），任务在服务端运行，关掉页面不丢；取消卡片或删除占位节点会同时取消云端任务。
- 视频文件和图片一样存在 `data/assets/`，随画板 zip 导出 / 导入；清理图片时，画板上还在用的视频会保留。

## 聚合API（唯一的生成后端）

```json
{ "gateway_url": "http://127.0.0.1:8880", "gateway_key": "", "gateway_timeout": 1800 }
```

- 图片生成卡片的模型菜单、顶部额度条、可用来源都来自聚合API；在聚合API管理页里停用 / 没配置的来源，画板里就不会出现。
- Flow 的地址、Key、打码、代理，ChatGPT 的浏览器扩展、额度，各平台的授权，都在聚合API那边设置（它可以托管 flow2api 子进程）；画布这边没有这些设置。
- 参考图只向聚合API上传一次（素材库按内容去重）；`<Picture N>` 引用由聚合API按各来源的写法改写。
- Flow 的 4K / 6K 仍由画布让 Flow 出较小的一档、再交给 ComfyUI 放大。「每个用户同时发给 Flow 的张数上限」「关闭的 Flow 模型」只对 Flow 生效。
- 旧画板里存的模型（如 `gemini-3.1-flash-image`、`gpt-image`）会自动对应到新的模型，不用改。
- 旧版 `config.json` 里的 `cloud_base_url` / `cloud_api_key` / `cloud_timeout` 仍然认；Flow / ChatGPT 的直连设置（`flow_base_url`、`gpt_base_url` 等）已不再使用，保存设置时会清掉（原文件留一份 `config.json.before-gateway`）。
- 以前直连 Flow / ChatGPT 的代码留在 `legacy/` 里备查（里面有从未提交过的 `gpt.py`），确认没问题后可以整个删掉。
