# Terry Flow

局域网多人使用的无限画布生图服务，后端对接自建的 [flow2api](../flow2api)。

- 卡片式工作流：**生成卡片**（提示词 / 模型 / 比例 / 分辨率 / 张数）→ 结果图片出现在卡片右侧。
- **连图**：从图片右侧圆点拖线到生成卡片左侧，该图就作为参考图；选中图片后，下方的选择条里「新建生成卡片」会新建一张已连好线的卡片（选多张图就一起作为参考）；
  选中单张图时选择条还有「下载」和删除，选中多张图时有「合并为集合」。
- 拖入图片 / 上传按钮 / Ctrl+V 粘贴都能把图片放上画布；双击图片大图预览，可下载原图。
- **参考集合**（底部「＋ 参考集合」或按 R）：把多张参考图放进一个节点，按槽位顺序排列；点空槽位或把图片拖到槽位上即可添加（一次拖多张会自动追加槽位），
  拖动卡片调整顺序，「✕」先清空图片、再点一次移除空槽位，选中集合后 Ctrl+V 可粘贴图片进去。一个集合可以连给任意多个生成卡片，卡片会按顺序拿到里面所有图片；
  框选画布上的图片后，选择条（出现在选中图片的下方）上的「合并为集合」可一键放进去，「新建生成卡片」则新建一张已连好这些参考图的卡片。
- 提示词里用 `<Picture N>` 引用第 N 张参考图（按连线顺序编号）：输入 `@` 弹出参考图菜单（↑↓ 选择，Enter/Tab 插入，Esc 关闭），
  粘贴带 `<Picture N>` 的文字会自动显示成带缩略图的标签；点标签可替换。发给 flow2api 时换成「图片N」。
- **编号不会错位**：每张卡片记住自己每张参考图的编号，换序、清空槽位都不会让 `<Picture N>` 指到别的图（已不存在的引用显示为红色标签）。
  提交时按编号排序发送参考图，并把提示词里的标签改写成「第几张发送的图」，所以提示词引用的图和实际提交的图一定一致；失效的引用会被丢掉并在卡片上提示。
- **一次拖入多张图**（拖拽、粘贴或上传多张）会弹出悬浮菜单：「散开」每张一个图片节点，或「集合」放进一个参考集合；按 Esc 或点空白处取消。
- **合并 / 解散**：框选图片后「合并为集合」会用集合替换这些散图，连线和提示词里的编号自动转给集合；集合标题栏的「解散」把它拆回独立图片节点，连线和编号保持不变。
- **图标**：生成卡片是香蕉、参考集合是四宫格、图片是图片图标，「生成」按钮带星光，左上角是品牌标志。
- **额度**：右上角用户名左侧显示 Nano Banana 2.1 今日额度（已用 / 总数，如 `3 / 1000`）和进度条，用到 70% 变黄、90% 变红；鼠标悬停看各模型用量。所有用户共用同一个 Flow 账号，每分钟和每次出图后刷新。
- **自动对齐**：左下角缩放按钮下方的对齐按钮（亮色为开启，设置会记住）。开启后拖动节点会吸附到其他节点的边缘和中心，并显示粉色虚线辅助线。
- 选中卡片或图片后，拖动边框和四角即可自由调整宽高（图片保持比例），尺寸随画板保存。
- 任务在服务端运行：关掉页面也不丢，重新打开会继续显示进度和结果。
- 多人并发：每张卡片的每一张图都是独立任务并行发给 flow2api；flow2api 的全局并发闸门
  （`[generation] image_max_concurrency`）负责限流和排队，超出的任务会显示「排队中」。
- 每个用户的画板分开保存（输入名字即可，没有密码，仅适合可信局域网）。

## 运行

```
python -m venv venv
venv\Scripts\pip install -r requirements.txt
copy config.example.json config.json   # 填 flow2api 地址和 API Key
cd web && npm install && npm run build  # 生成 web/dist
start.bat                               # 默认 http://<本机IP>:8870
```

画板、图片、任务记录保存在 `data/`（`canvas.db` 和 `assets/`）。

## 在 config.json 里关闭选项

```json
{
  "disabled_models": ["gemini-3.1-flash-lite-image"],
  "disabled_sizes": ["4K"],
  "max_count": 2
}
```

- `disabled_models`：按模型系列 key 关闭模型（key 见 `/api/models`），界面里不再显示，接口也会拒绝。
- `disabled_sizes`：关闭分辨率（`"1K"` / `"2K"` / `"4K"` / `"6K"`）。也可以在控制台“设置”里把某个分辨率的来源设为“关闭”。
- `max_count`：一张卡片一次最多生成几张（1–8，默认 4）。
- 改完重启服务生效；画板里已经选了被关闭选项的卡片，打开时会自动改成可用的值。

## ComfyUI 放大（可选）

在控制台点“设置”：填 ComfyUI 地址、选放大方案（SeedVR2 或 PiD），并为 1K / 2K / 4K / 6K 各选来源。选“ComfyUI 放大”的分辨率，由 Flow 先按“基础尺寸”出图，再放大到“目标长边”像素。画板里选中一张图，选择栏会出现“放大到 4K”，结果放在右边的新图里。放大模型文件名等高级项在 config.json 的 `comfyui` 里（`seedvr2` / `pid`）。保存设置立即生效。

```json
{
  "comfyui": {"url": "http://127.0.0.1:8188", "upscale_engine": "seedvr2"},
  "resolutions": {"4K": {"route": "comfy", "base": "2K", "target": 4096}}
}
```

## 开发

```
venv\Scripts\python -m pytest          # 后端测试（用假的 flow2api）
cd web && npm run dev                  # 前端开发服务器 :5180，/api 代理到 :8870
```

## 已知限制

- 只做图片（含 2K/4K，按模型选择）；视频和其他平台未接入。
- 没有账号体系；同一个名字就是同一个人。
- 同时生成的数量受 flow2api 的 Google 账号额度和并发闸门限制，积分是共享的。
